专为多 Agent 开发者打造的核心工程设计

追求极致的安全防护、毫秒级响应以及遵循常规文件管理习惯。

🚀

零 npm/npx 臃肿依赖

基于 GraalVM Native Image 编译为单文件原生可执行程序。无需 Node.js 运行时，彻底告别脆弱的 npm 包依赖网络与幽灵锁文件。

📁

双轨内容架构设计

原创草稿以常规文件放在 skills/ 自动发现；第三方依赖以元数据记录在 skillkit.json。无繁琐的导入或注册流程。

⚡

Java 25 虚拟线程高并发

利用 Project Loom 虚拟线程并发执行来源解析与快照下载（--jobs 8），非阻塞、有界并发，毫秒级响应。

🛡️

作用域推送保护机制

skillkit push 严格仅自动提交 skills/ 与 skillkit.json 路径，绝不污染或误提工作区中的其他代码修改。

🔒

本地手改防覆盖屏障

通过 .skillkit-state.json 维护加密内容摘要。如果你在某个 Agent 目录里手动修改了该 Skill，工具会智能识别并拒绝静默覆盖。

🤖

原生 Agent Skill 协议

全面适配 agentskills.io 标准。支持 skillkit list --json 机器可读输出，AI Coding Agent 可自主感知和调度。

精炼的 5 大命令体系

满足从本地编写、依赖追踪、批量并行更新到私有源发布的完整闭环。

install skillkit install <names...> [--repo <source>] [--symlink] [--jobs <n>]
复制或软链分发至全部 10 个 Agent 目录

安装原创 Skill（从 skills/ 自动发现）或外部仓库项（指定 --repo owner/repo）。外部安装会自动记录来源、路径与 commit 到 skillkit.json。

update skillkit update [names...] [--jobs <n>] [--dry-run]
并行刷新已安装的全部或指定 Skills

比对本地原稿改动与上游 Git 远端最新提交，通过有界虚拟线程高并发拉取并同步到各 Agent（默认并发数为 4）。

uninstall skillkit uninstall <names...> [--dry-run]
全局干净卸载，保护原稿记录

从所有 Agent 目标中安全清理对应目录，同时完整保留个人 skills/ 原稿与 skillkit.json 来源配置。

list skillkit list [--json]
全局安装状态与版本概览

清晰列出所有已分发技能的安装模式（复制/软链）、来源仓库、解析提交版本以及所托管的 Agent 目录列表。

push skillkit push [-m <msg>] [--repo <dest>] [--dry-run]
一键发布至个人 Git 私有源

普通目录首次使用自动初始化 Git 并配置 origin；自动提交 skills/ 和 skillkit.json 的新增、修改与删除，安全推送到远端。

极速安装指引

单文件原生可执行程序。无需 JVM，无需 npm，无需 Python 环境。

macOS 与 Linux (一键脚本) curl
curl -fsSL https://tools.lihu.me/install.sh | bash -s skillkit

直接下载对应架构的原生可执行二进制至 ~/.local/bin/skillkit。

Windows 11 (PowerShell) irm
irm https://tools.lihu.me/install.ps1 | iex

全自动解压 Windows 64位 原生二进制并写入用户级环境变量 PATH。

Homebrew Tap (macOS / Linux) brew
brew install lihuu/tap/skillkit

官方维护的 Homebrew Formula，支持跟随版本更新。

Scoop Bucket (Windows) scoop
scoop install skillkit

Windows 开发者的极佳包管理选择。

常见问题解答

skillkit 与社区现有的 npm/npx 类 Skills 管理工具有什么本质不同？

社区方案通常依赖数百兆的 Node.js 运行时环境，通过 npm 下载大量间接依赖，容易产生全局状态冲突且操作繁琐。skillkit 是一个体积不足 30MB 的单文件原生二进制，借助 Java 25 原生编译与系统 Git 交互，直接面向 10 个主流 Agent 目录进行广播，原生支持作用域 Git 提交，无任何运行时负担。

支持从 GitHub 私有仓库中安装 Skills 吗？

完全支持。skillkit 底层直接调用本机的 git 命令行工具，天然复用你现有的 SSH Key、GitHub CLI (gh) 凭据与 Git 签名配置，工具自身不窃取、不保存也不中转任何私钥或 Token。

当多个 Agent 共享同一个路径时，skillkit 会重复写入吗？

不会。skillkit 在写入前会先对所有解析后的绝对路径进行合并与去重（如 Codex 与 Pi 共享的 ~/.agents/skills/），同一物理路径在单次操作中仅执行一次文件写入，并统一维护状态记录。

支持软链接（Symlink）安装模式吗？

支持。只需在安装时加上 --symlink 参数，skillkit 就会将各 Agent 目录软链至本地原稿或固化提交的缓存快照。后续执行 update 时，工具会自动保持各技能已设定的安装模式。
