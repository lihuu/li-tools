Five Clean Commands. Zero Bloat.

Everything you need to author, install, update, and distribute skills.

install skillkit install <names...> [--repo <source>] [--symlink] [--jobs <n>]
Copy or symlink to all 10 agent directories

Installs your own skills from skills/ or external repositories via --repo owner/repo. External installations automatically record source, path, and resolved commit in skillkit.json.

update skillkit update [names...] [--jobs <n>] [--dry-run]
Parallel refresh of all installed skills

Checks all active installations against current local files or upstream Git commits. Executes bounded virtual-thread network fetches (default jobs = 4).

uninstall skillkit uninstall <names...> [--dry-run]
Clean global removal

Removes target directories from all global agent roots. Safeguards your original drafts in skills/ and retains upstream metadata in skillkit.json.

list skillkit list [--json]
Tabular status and agent overview

Displays an aggregated table of all installed skills, installation types (copy / symlink), active source repositories, and resolved Git commits.

push skillkit push [-m <msg>] [--repo <dest>] [--dry-run]
Publish to personal Git remote

Auto-initializes Git if needed, saves remote origin, stages additions/deletions only under skills/ and skillkit.json, and pushes to your remote distribution source.

Frequently Asked Questions

How does skillkit differ from community npm/npx-based skill tools?

Existing tools typically require a heavy Node.js runtime, download dozens of transitive dependencies via npm, and often modify unrelated global files. skillkit is a single native binary (<30MB) powered by Java 25 and GraalVM. It uses your system's native Git for secure authentication, enforces strict commit scoping, and fans out directly to all major agent directories without runtime friction.

Can I install skills from private GitHub repositories?

Yes. skillkit orchestrates your system's native git CLI. It inherits your existing SSH keys, GitHub CLI (gh) credential helpers, and commit signing keys automatically without ever reading or copying private tokens.

What happens if two agents share the same skills path?

skillkit resolves and de-duplicates target paths before executing file operations. Shared directories (like ~/.agents/skills/ shared by Codex and Pi) are written exactly once and cleanly tracked in state files.

Does skillkit support symlinks instead of copying?

Yes! Running skillkit install my-skill --symlink creates symbolic links to your local repository or immutable cache snapshots. When updating, skillkit automatically respects each skill's established installation mode.
