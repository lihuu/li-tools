❌ The Pain of Traditional GPG

  • • Impossible flags: Searching docs for --keyid-format=long every time
  • • Unverified backups: Exporting files only to discover they fail to restore on a new machine
  • • Tedious trust setup: Manually setting trust level trust -> 5 -> save
  • • Headless hang: GUI pinentry prompts freezing CI pipelines and remote SSH terminals

✅ The gpgkit Solution

  • • Intuitive verbs: gen, backup, restore, doctor
  • • Mandatory loopback check: Proves restoration and signature verification before disk write
  • • Non-interactive design: Pinned batch flags prevent terminal and CI deadlocks
  • • Zero JVM dependency: Standalone native binary runs instantly without Java pre-installed

Command Matrix

gpgkit status

Inspect local key fingerprints, expiry days, secret key presence, and keyserver visibility with a clear OK/WARN conclusion.

gpgkit gen

Generate a modern signing key pair (rsa4096 / 2y expiry) auto-configured with git identity, followed by an immediate backup prompt.

gpgkit backup

First-class citizen: exports encrypted secret key with metadata, running immediate loopback restoration and test signing before writing to disk.

gpgkit restore <backup-file>

Restores backup on a fresh machine, sets ultimate trust level automatically, and verifies signature production on the spot.

gpgkit extend [--by 2y]

Extends validity for master key and all subkeys with a single command, preventing git commit signatures from suddenly invalidating.

gpgkit doctor

Comprehensive health check: verifies gpg engine, backup existence, passphrase file permissions, and outputs a one-line conclusion.

Frequently Asked Questions

What is the "Loopback Test" in gpgkit backup?

During every backup, gpgkit spins up an ephemeral scratch keyring in memory, imports the newly created backup archive, decrypts it, generates a detached signature on dummy data, and verifies the signature. Only when all checks succeed does it write the backup to ~/.gpgkit/backups/.

Does gpgkit replace GnuPG?

No. gpgkit is an intelligent, safety-enforcing orchestrator around the standard gpg engine. It takes care of arcane flags, directory standards, and verification safeguards so you never mess up GPG configurations.
