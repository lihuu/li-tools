Enterprise-Grade Cryptographic Design

Every component follows strict zero-trust standards to guarantee defense in depth.

🛡️

AES-256-GCM + Canary

All token values are encrypted using AES-GCM with 12-byte cryptographically random nonces and 16-byte authentication tags. Any offline file tampering fails immediately with AEADBadTagException.

🔐

OS Native Keychains

Master keys are automatically backed by macOS Keychain, Windows DPAPI (CryptProtectData), or 0600 POSIX keyfiles on Linux. In headless CI/CD environments, TOKENKIT_MASTER_KEY takes precedence.

📦

Safe Cross-Machine Migration

Switching laptops or synchronizing across servers? tokenkit export encapsulates secrets into a passphrase-protected .tkbundle using PBKDF2 (100,000 rounds). Import defaults to safe conflict skipping.

Frequently Asked Questions

Everything you need to know about security, performance, and cross-platform compatibility.

Why not just put API keys in ~/.zshrc or ~/.bashrc?

Placing plaintext credentials in shell configuration files exposes them to shoulder surfers, accidental screen shares, malicious dotfile git syncs, and every script running on your machine. tokenkit ensures tokens stay encrypted on disk and are only decrypted dynamically into memory when needed.

How fast is tokenkit env in shell startup scripts?

Cold startup execution benchmarks take under 10 milliseconds. Adding eval "$(tokenkit env)" to your .zshrc or PowerShell $PROFILE introduces zero perceptible startup delay.

Does tokenkit require Java/JVM on my system?

No. All binaries are pre-compiled ahead-of-time using GraalVM Native Image into self-contained native executables for macOS, Linux, and Windows 11. No JVM, JRE, or Java installation is required.

How does tokenkit compare to 1Password CLI or Doppler?

1Password CLI and Doppler are cloud-first tools requiring active internet connectivity and desktop daemons that add 150-350ms of network overhead per command. tokenkit is 100% offline, zero-network, sub-10ms fast, and fully open-source under Apache-2.0.
