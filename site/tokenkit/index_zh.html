企业级加密与纵深防御

每一个细节均遵循零信任原则，彻底杜绝侧信道泄密。

🛡️

AES-256-GCM + 金丝雀

所有 Token 值均采用 AES-GCM 认证加密，每次生成独立的 12 字节强随机 Nonce 与 16 字节 Auth Tag。离线篡改任何字节解密时直接抛出 AEADBadTagException 崩溃熔断。

🔐

原生系统主钥匙串

主密钥自动受 macOS Keychain、Windows DPAPI (CryptProtectData) 或 Linux 0600 POSIX 专用私钥文件保护。在无界面 CI/CD 环境中，自动以 TOKENKIT_MASTER_KEY 为准。

📦

跨机器无缝加密迁移

更换电脑或同步服务器？使用 tokenkit export 输入中转密码，通过 PBKDF2（100,000 次哈希）封装为独立的 .tkbundle 迁移包。目标机器导入时默认冲突安全跳过并给出清晰的彩色汇总。

清晰极简的命令行心智

符合直觉的日常动词，零繁琐参数。

tokenkit set <NAME> [value]
存入或更新 Token。支持显式传参、管道导入（cat key.pem | tokenkit set KEY）或控制台隐藏输入。
tokenkit get <NAME> [--clip]
输出明文（不带尾随换行符，便于管道透传），或直接复制进系统剪贴板。
eval "$(tokenkit env)"
<10ms 全量导出当前环境 Token 为 zsh/bash/pwsh/fish 变量声明，放入 .zshrc 毫无卡顿。
tokenkit run -- <cmd...>
启动子进程并单次注入解密环境变量，完全不污染当前终端会话上下文。
tokenkit profile <use|create|list|rm>
多环境隔离分组（default、work、staging），切换后后续命令自动生效。
tokenkit export & import <file>
跨操作系统密码加密迁移包（.tkbundle）打包与导入，附带彩色冲突检测报告。

常见问题解答

关于安全性、启动耗时与跨平台兼容性的一切。

为什么不推荐直接在 ~/.zshrc 或 ~/.bashrc 声明环境变量？

把明文 API 密钥写在 Shell 配置文件中，任何本地应用或被投屏窥视都能一览无遗，更极易随 dotfiles 上传至 GitHub 导致凭据泄露。tokenkit 保证磁盘上只有 AES-256-GCM 密文，仅在开启会话时由内存动态解密。

写入 .zshrc 后，打开新终端窗口会不会变慢？

完全不会。tokenkit env 在实测中冷启动至全部导出完成通常仅需 2 到 8 毫秒，人类感知阈值通常在 100ms 以上，开窗体验丝滑顺畅。

tokenkit 需要我在本地安装 Java 运行环境吗？

完全不需要。所有发布制品均使用 GraalVM Native Image 提前编译为原生机器码（独立单一可执行文件），目标设备无需安装 JDK 或 JRE。

相比 1Password CLI 或 Doppler，tokenkit 的核心优势是什么？

1Password CLI 和 Doppler 是云优先产品，每次执行都需要联网与远端握手通信，单次耗时常在 150ms 到 350ms 之间，离线或弱网下甚至直接报错。tokenkit 100% 离线、零网络依赖、<10ms 极速响应，并且完全基于 Apache-2.0 开源。
