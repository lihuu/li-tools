JSON, readable.
And queryable.

One command to format a file, highlight it in the terminal, and select exactly the value you need. No jq dependency, no subcommand, no second tool.

$ jsonkit response.json
$ jsonkit response.json -p user.name
$ curl -s "$API" | jsonkit -p 'items[*].id'

One gesture, two questions

“Show me this JSON”

Pretty-print with two-space indentation, preserve member order and number literals, and highlight keys, strings, numbers and literals only when stdout is a terminal.

$ jsonkit package.json
{
  "name": "example",
  "version": "1.0.0"
}

“Give me this value”

Add -p and use standard JSONPath. A field/index path prints one value; wildcards, slices, descendant queries and filters print an array.

$ jsonkit -p "items[?@.status == 'failed'].id" response.json
[
  1,
  3
]

After the root is added, the expression follows RFC 9535: field names, indexes, wildcards, slices, selector lists, recursive descent, filters and standard functions.

An output contract agents can trust

Single value

Root, field and index paths print the selected JSON value. A missing path exits 1.

Array result

Wildcard, slice, selector list, descendant and filter paths always print an array. No match prints [] with exit 0.

Plain by default

Redirection, --no-color and NO_COLOR produce plain UTF-8 JSON. Color depends only on stdout being a terminal.

ExitMeaning
0Success, help, version, or multi-value query with []
1Read failure, invalid JSON, duplicate keys in query input, missing single value, or a resource limit
2CLI usage error or invalid JSONPath expression

Formatting preserves number literals exactly, accepts UTF-8 BOM, and rejects empty, truncated or trailing content. Query input with duplicate object keys fails instead of silently choosing one.

FAQ

Why not just use jq?

If jq is already installed, it is excellent. jsonkit exists so the formatting step and the query step are one dependency-free native command on all three platforms, with an explicit automation output contract.

Can it read stdin?

Yes. With no file, it reads stdin when it is piped or redirected. In a terminal it shows help instead of waiting. Use - to read a terminal until EOF.

Does it preserve huge integers?

Yes. Numbers are written from their original literals, so a 30-digit integer or a decimal with trailing zeros survives formatting and query selection unchanged.

What are the query limits?

10,000,000 visited nodes, 1,000,000 result nodes and 1,000 levels of nesting. Exceeding a limit exits 1 with a diagnostic instead of exhausting the process.
