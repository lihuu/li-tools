Frequently Asked Questions

Do I need to install Java on my machine to run li-tools?

No. Although developed using Java 25, all binaries are compiled ahead-of-time with GraalVM Native Image into native machine code. They run directly like any standard C or Rust CLI tool.

How does certkit provide green-lock HTTPS without browser warnings?

By running certkit ca, certkit generates a dedicated local Root CA and injects it into your OS trust store. All certificates generated with certkit gen are signed by this CA and include modern SAN extensions.

How does gpgkit guarantee I will never lose my key?

Every backup operation enforces a mandatory round-trip loopback test inside an isolated scratch keyring. It restores the backup and verifies a test signature on the spot before saving the file.
