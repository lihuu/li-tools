🚀

单一原生二进制

GraalVM Native Image 提前编译。无需 JVM、无需安装步骤——直接放进 CI 容器、Alpine 镜像或离线服务器。

⚡

自适应并行扫描

ForkJoinPool 自适应分叉：子目录数达到阈值自动派发工作线程，小目录树直接在当前线程内联完成。实测 59 GB、66 万文件的目录树：3.2 秒，而 ncdu 需要 8 秒。

🧭

全屏交互 TUI 浏览

现代化全屏双缓冲界面：方向键移动、Enter 下钻、Backspace 返回、s 切换排序。基于 JLine FFM 原生接入，Windows 11 控制台、Terminal 与 SSH 会话完全平权。

📤

Directories-Only JSON 树

树节点仅包含目录，常规文件汇总折叠为统计指标，体量只跟目录数相关而不随文件爆炸。零反射流式写出，Agent 与 CI 上下文可极速消费。

⚖️

诚实的尺寸语义

默认报告磁盘实际占用（FFM 读 st_blocks），与 du 和 Finder 完全对齐；--apparent-size 可切换为表观大小。硬链接单次扫描只计一次，符号链接永不跟随。

🛡️

安全回收站与文件预览

按 d 弹出模态确认后安全移入系统回收站（macOS ~/.Trash / Linux Trash / Windows 回收站），绝不硬删。按 t 展开当前目录直属最大文件预览。

三个命令。这就是全部。

完整目录树、有界排行，或交互式浏览。其余一切都是选项。

scan dukit scan [路径] [--depth <n>] [--apparent-size] [--exclude <glob>...] [--text]
完整目录树，默认 JSON

一次遍历目录树，输出每个目录及其真实占用。树中只有目录——文件折叠进父目录的统计字段，因此体积只跟目录数相关，不再随文件数爆炸。--depth 裁剪层数，但聚合值始终覆盖完整子树：实测扫描 /Applications，全量 11 MB，--depth 2 只有 30 KB。--apparent-size 切换为表观大小，--text 切换为人类可读文本树。

top dukit top [路径] [--limit <n>] [--files] [--min-size <大小>] [--json]
有界排行，流式计算

不建树就能回答“哪里最大”。两个有界堆只保留最大的条目，内存只跟 --limit 相关，与磁盘体量无关。--files 排行单个文件而非目录；--min-size 1G 过滤掉更小的项。20 条结果的 JSON 约 2 KB。

browse dukit browse [路径] [--exclude <glob>...]
全屏交互浏览

极速扫描后接管终端进入备用屏幕：方向键选择、Enter 下钻、Backspace 返回、s 循环切换 大小 → 名称 → 文件数、t 展开直属前 10 大文件预览、d 弹出模态确认后安全移入系统回收站（绝不硬删）。始终按占用降序并默认选中首项。在非交互式管道中自动平滑降级为 JSON 树输出。

常见问题

dukit 报的是实际磁盘占用还是表观大小？

默认报告实际磁盘占用（diskSize）：通过 Java 25 FFM API 读取平台原生 st_blocks，与 du 和 Finder 完全一致。使用 --apparent-size 可切换为逻辑大小，JSON 输出中两者同时并存。在 sparse 稀疏文件与 APFS 写时复制（CoW）克隆上，两者可相差几个数量级。Windows 环境下由于未暴露块计数，优雅回退为逻辑大小。

dukit 的数字与 du、ncdu 相比如何？

默认数字与 du -s 实际分配完全对齐。同一扫描内具有相同 inode/fileKey 的硬链接仅计算一次占用（所有硬链接仍计入文件总数），符号链接永不深入递归，目录 inode 自身不额外计入。不可读路径作为告警收集到 stderr，扫描继续完成，杜绝单点权限受阻。

dukit 能安全删除目录吗？

可以，但只能在交互式浏览器中进行。选中目录按 d 会弹出全屏居中确认模态，核对完整路径与大小后按 y 移入系统回收站（macOS ~/.Trash、Linux freedesktop Trash、Windows 回收站），按 n 或 Esc 取消。dukit 绝不执行不可逆的硬删除，也不提供 CLI 删除参数。

全屏交互浏览支持 SSH 与 Windows 吗？

完全支持。dukit browse 采用 JLine 的 FFM 原生终端接入驱动备用屏幕，在经典 Windows 控制台、Windows Terminal、tmux 面板与 SSH 会话中均提供丝滑的全屏双缓冲交互与键盘上下选择体验。若在无法进入原始模式的受限管道中，会自动平滑降级。
